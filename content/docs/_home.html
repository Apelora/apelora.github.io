How to read the evidence labels

Results are labelled by how they were checked. A label is never stronger than its evidence.

Real Incus tested
Run against a real Incus cluster: the {{fact:labServersWord}}-server lab of virtual machines.
Real MAAS tested
Run against a real MAAS, again in the lab.
Contract verified
Checked against recorded responses or a server shaped like the real one.
Mock verified
Checked against Apelora's mock provider and stubbed services. The screens say "Mock" until they show real data.
Not verified
Written from the upstream documentation; nothing has run it yet.
