    MCP and tooling: what runs where

    MCP servers give Claude Code tools. They are developer-workstation helpers, not part of the product and not services the Apelora cluster runs.

    ToolWhereStatusNotes
    Playwright MCP (@playwright/mcp, pinned 0.0.83)Local stdio, launched on demandConfigured in .mcp.json (Chromium, headless)Needs Chromium: npx playwright install chromium. Drives the Vite dev server on 127.0.0.1 only. Restart Claude Code after changing .mcp.json.
    Playwright Test (@playwright/test)Local / CIUsed for the repeatable suite in tests/e2eSame browser as above.
    daisyUI skill.claude/skills/daisyui (installed with npx skills add saadeghi/daisyui)InstalledDocs only, no server. Review before upgrading; it is third-party instructions.
    Context7 MCP (pinned 4.4.1)Local process calling a hosted docs serviceOptional, configuredLibrary-doc queries leave the machine; do not include proprietary code in queries.
    Inspo / Figma MCPUser-level (not in .mcp.json)OptionalDesign references only; project conventions win.
    GitHub MCPLocal Docker with OAuth, machine-local configNot configuredPrefer OAuth over tokens; least privilege; never commit credentials.
    Filesystem MCP—Not installedClaude Code already has file tools; extra access = extra attack surface.
    Apelora dev MCP (catalog/validate, read-only)tools/mcp/apelora-dev, local stdioFutureMust not run Incus operations.
    Incus / control plane / cluster member APIsRust management planeFuture, not MCPAuthenticated, audited; never exposed to an AI agent unrestricted.

    Rules

    1. Bind dev servers to 127.0.0.1. Do not open MCP or Vite ports to a network or to dom0.
    2. No secrets in .mcp.json. Use env vars or the OS keyring.
    3. Pin execution tools (@latest only to bootstrap); review updates.
    4. Browser automation targets only the local dev server; tests assert there are no requests to external hosts.

    Verifying

    claude mcp list
claude mcp get playwright
npx playwright --version && npx playwright test      # independent of MCP
