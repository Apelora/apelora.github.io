    Audit API

    The append-only audit log: search and export. This page documents all 2 operations, each with a request you can copy. Set APELORA_URL and APELORA_TOKEN as described in the API overview.

    Operations

    OperationWhat it does
    undefinedAudit events the caller may read, newest first, filtered by actor, target, action prefix, outcome and time, and paged with before.
    undefinedExports the audit events the caller may read, with the same filters as the list (limit does not apply), newest first, as CSV or JSON lines.

    Details

    GET /api/v1/audit

    Audit events the caller may read, newest first, filtered by actor, target, action prefix, outcome and time, and paged with before.

    Needs: audit.read (platform-wide, or limited to the events of the caller's organisations, projects and applications) and a database.

    ParameterInTypeRequiredMeaning
    actorquerystringnoWho acted: their stable id (user:<uuid>, service:<uuid>, token:<name>) or, ignoring case, the name they had when they acted.
    targetquerystringnoWhat was acted on, exactly as recorded (e.g. local-account:ada or a group's name).
    actionquerystringnoOnly actions starting with this, e.g. role. or emergency_access..
    outcomequerystringnosuccess, denied or failed.
    fromquerystringnoRFC 3339: events at or after this time.
    toquerystringnoRFC 3339: events before this time.
    beforequeryintegernoOnly events older than this id (paging: the id of the last event of the previous page).
    limitqueryintegernoEvents per page, 1 to 500 (default 100). Not used by the export.
    curl -sS -X GET "$APELORA_URL/api/v1/audit" \
  -H "Authorization: Bearer $APELORA_TOKEN"

    Response 200:

    {
  "items": [
    {
      "action": "example",
      "actor": "example",
      "actorType": "example",
      "at": "2026-01-01T09:00:00Z",
      "detail": {},
      "id": 1,
      "outcome": "example",
      "target": "example",
      "actorName": "example",
      "scope": {}
    }
  ]
}

    Errors: 400, 401, 403, 503. The body is { "error": { "code": …, "message": … } }.

    GET /api/v1/audit/export

    Exports the audit events the caller may read, with the same filters as the list (limit does not apply), newest first, as CSV or JSON lines. Streamed one database page at a time.

    Needs: audit.read; the export itself is audited as audit.exported with its filters.

    ParameterInTypeRequiredMeaning
    actorquerystringnoWho acted: their stable id (user:<uuid>, service:<uuid>, token:<name>) or, ignoring case, the name they had when they acted.
    targetquerystringnoWhat was acted on, exactly as recorded (e.g. local-account:ada or a group's name).
    actionquerystringnoOnly actions starting with this, e.g. role. or emergency_access..
    outcomequerystringnosuccess, denied or failed.
    fromquerystringnoRFC 3339: events at or after this time.
    toquerystringnoRFC 3339: events before this time.
    beforequeryintegernoOnly events older than this id (paging: the id of the last event of the previous page).
    limitqueryintegernoEvents per page, 1 to 500 (default 100). Not used by the export.
    formatquerystringnocsv or jsonl (one JSON object per line, as the list returns them). Default jsonl.
    curl -sS -X GET "$APELORA_URL/api/v1/audit/export" \
  -H "Authorization: Bearer $APELORA_TOKEN"

    Response 200, with no body.

    Errors: 400, 401, 403, 503. The body is { "error": { "code": …, "message": … } }.

    This page is a copy of packages/api-client/openapi.json in the repository, which is the source of truth. Suggest a change.
