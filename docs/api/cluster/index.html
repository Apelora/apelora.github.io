    Cluster API

    The cluster's servers: members and their maintenance (evacuate, restore, remove, fencing), rolling upgrades, cluster settings and groups, recovery, machines and join tokens, and MAAS provisioning. This page lists 30 operations.

    Set variables in the API overview. Download OpenAPI.

    Operations

    OperationWhat it does
    GET /api/v1/cluster/groupsCluster groups and their members (empty on a standalone server).
    GET /api/v1/cluster/join-tokensJoin tokens waiting to be used (no secrets).
    POST /api/v1/cluster/join-tokensApproves a new cluster member: asks Incus for a single-use join token.
    DELETE /api/v1/cluster/join-tokens/{member}Withdraws a new member's approval: revokes its unused join token.
    GET /api/v1/cluster/membersMembers with their database role (voter, stand-by, spare), the leader, other roles, failure domain, groups and Incus release; the database majority (how many voters answer, how many are needed, how many more can be lost); and version skew against the pinned Incus release with what blocks an upgrade.
    POST /api/v1/cluster/members/{member}/evacuateEvacuates a cluster member through Incus after re-running the dry run: refused while anything blocks it.
    GET /api/v1/cluster/members/{member}/evacuationDry run of evacuating a cluster member: per instance, what Incus will do and what it means for the application; what blocks it; what to accept.
    POST /api/v1/cluster/members/{member}/fencingConfirms that a failed server is powered off (or cut off from the shared storage).
    GET /api/v1/cluster/members/{member}/removalDry run of removing a cluster member for good: what is still on it, what blocks it and what to accept.
    POST /api/v1/cluster/members/{member}/removeRemoves an evacuated, empty member from the cluster for good, after the check runs again: refused while anything blocks it.
    POST /api/v1/cluster/members/{member}/restoreRestores an evacuated member: Incus moves its instances back and starts them.
    GET /api/v1/cluster/recoveryFailed members: whether each is fenced (and the evidence), or why Apelora waits; and per instance whether it restarts on another server (and where) or waits (and why).
    GET /api/v1/cluster/settingsCluster-wide settings (offline and healing thresholds, database voters and stand-bys, join-token lifetime, image replication and updates): the value set, Incus's default and whether the default applies.
    PATCH /api/v1/cluster/settingsChanges cluster settings through Incus with the admin identity.
    POST /api/v1/cluster/upgradeOne step of the rolling upgrade.
    GET /api/v1/machinesMachines being enrolled, with their state derived from Incus.
    POST /api/v1/machinesRegisters a machine.
    DELETE /api/v1/machines/{name}Forgets a machine that is not a cluster member (revoking an unused join token).
    GET /api/v1/machines/{name}/admissionThe admission checks for a joined machine (dry run; changes nothing).
    POST /api/v1/machines/{name}/admitAdmits a joined machine: re-runs the admission checks and, when none fails, lets Incus place instances on it.
    DELETE /api/v1/machines/{name}/approvalWithdraws an approval: revokes the machine's unused join token.
    POST /api/v1/machines/{name}/approveApproves a machine: asks Incus for its single-use join token, returned only in this response with the command to run on the server.
    GET /api/v1/provisioners/maas/machinesThe machines MAAS manages, with the Apelora machine and Incus member each became.
    POST /api/v1/provisioners/maas/machines/{systemId}/commissionStarts commissioning.
    POST /api/v1/provisioners/maas/machines/{systemId}/deployInstalls an operating system.
    POST /api/v1/provisioners/maas/machines/{systemId}/releaseReturns the machine to MAAS's pool.
    POST /api/v1/provisioners/maas/machines/{systemId}/testStarts a hardware test run (burn-in) through MAAS.
    GET /api/v1/sectorsThe sectors this control plane knows and whether each answers.
    POST /api/v1/sectorsRegisters another Incus cluster as a sector.
    DELETE /api/v1/sectors/{name}Forgets a registered sector.
